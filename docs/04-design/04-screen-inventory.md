## Screen states checklist (docs/11 P4)
Every list screen has **loading** (server-rendered, so none visible), **empty** (e.g. 40, 63 – "No jobs yet",
"Nothing to review 🎉"), **error** (problem message + request id) and **success** (status alerts, e.g. 43, 48)
states.
