## 1. Value proposition canvas

### Candidates (Amira)

| Customer profile | | Value map | |
|---|---|---|---|
| **Jobs to be done** | Find a suitable job; know where each application stands | **Products & services** | Search of verified jobs; saved profile + CVs; application status tracking |
| **Pains** | Silence after applying; scam adverts; retyping the same details | **Pain relievers** | Status timeline on every application; verified-only employers; apply with a saved CV |
| **Gains** | Speed; confidence; a sense of progress | **Gain creators** | Apply in ≤ 3 clicks (NFR-UX-003); "✓ Verified employer"; clear salary and closing date on every job |

### Employers (David)

| Customer profile | | Value map | |

| Customer profile | | Value map | |

## 2. Positioning

> **For** job seekers and hiring companies in the UK **who** are tired of applications disappearing and of
> scam adverts, **JobConnect** is a job marketplace **that** shows every application's real status and only
> lists verified employers. **Unlike** generic job boards, every company and every job is checked by a
> person before candidates see it.
